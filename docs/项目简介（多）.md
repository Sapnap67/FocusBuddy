## 一、项目简介

### 100字版

**FocusBuddy** 是一款摄像头实时检测面部朝向、配合番茄钟和ESP32像素宠物的学习专注伴侣。
我们发现学生自习时走神了自己也不知道，于是做了"摄像头检测+番茄钟+像素宠物表情反馈"闭环。
用户打开网页、允许摄像头，系统会自动判断是否专注，走神时宠物变担心、离开时宠物睡觉。
用MediaPipe FaceMesh做面部检测，ESP32-S3 Matrix驱动8×8像素宠物。

### 200字版

**FocusBuddy** 是一款利用摄像头实时检测专注状态的学习辅助工具。

**痛点：** 学生自习时经常走神而不自知，番茄钟只管定时不管你是否真的在看屏幕。反馈延迟 = 行为难以纠正。

**方案：** 摄像头通过 MediaPipe FaceMesh 468点面部网格实时检测面部朝向、闭眼和转头，判断"专注/走神/离开"三种状态。番茄钟（25/5 min）倒计时同步显示在 ESP32-S3 8×8 LED 矩阵上，同时像素宠物根据专注状态变化表情（开心😊/担心😟/愤怒😡/睡觉😴）。走神超过3秒弹出警告，离开屏幕自动暂停番茄钟。全程数据记录在 localStorage，提供 Chart.js 专注率饼图和7天趋势柱状图。

**团队：** Vickie（FaceMesh算法+ESP32固件）、Ryan（Web前端+番茄钟+统计+UI）

### 正式版（提交用）

```
# FocusBuddy — 学习专注伴侣

## 一句话
摄像头盯着你学习，不好好学习你的像素宠物会饿死 🐱

## 痛点
- 走神不自知：学一会儿就刷手机，不知道自己偷懒了多久
- 缺乏动力：番茄钟太枯燥，没人监督容易放弃
- 不了解自己：不知道一天真正专注了多少时间
- 提醒太烦：手机闹钟不是忘了就是嫌烦关掉

## 解决方案
FocusBuddy 用摄像头捕捉面部特征，通过 MediaPipe FaceMesh 进行 468 点面部网格分析，
实时判断专注/走神/离开状态，联动：
- 🍅 番茄钟倒计时（25分钟专注 / 5分钟休息）
- 🐱 ESP32 8×8 LED 像素宠物（4种情绪表情实时变化）
- 📊 专注统计仪表盘（当日数据 + 图表分析）
- 📋 今日计划（输入提示词自动生成待办清单）

## 技术实现
- 面部检测：MediaPipe FaceMesh（Web端），闭眼检测(EAR)、低头检测(headRatio)、转头检测(turnRatio)
- 前端：原生 HTML/CSS/JS + Chart.js
- 硬件：ESP32-S3-Matrix (8×8 NeoPixel)，WiFi AP模式，HTTP API通信
- 存储：localStorage（专注统计、设置、计划）

## 创新点
- 物理反馈（LED宠物）比软件弹窗更温和但有效
- 番茄钟 × 面部检测的闭环联动
- 8×8 矩阵显示数字倒计时（自定义5×3字体）
- 纯浏览器端运行，无需安装

## 使用方式
1. 打开 https://github.com/Sapnap67/FocusBuddy
2. 启动本地 HTTP 服务器 (python -m http.server 8080)
3. 浏览器打开 index_new.html，允许摄像头
4. 点击"开始专注"开始学习

## AI工具使用声明
本项目在编程辅助中使用AI工具（代码生成和调试辅助），
核心创意、功能设计和关键算法逻辑由团队独立完成。
面部检测算法（EAR/headRatio/turnRatio）基于团队先前项目(专注力检测器)自主研发，
ESP32固件和Web前端为团队独立编写。
```

## 二、技术流程概要

```
用户开打网页
    ↓
允许摄像头 → MediaPipe FaceMesh 加载 (CDN)
    ↓
468点面部网格实时追踪
    ├─ EAR闭眼检测 (<0.22 持续>800ms → 闭眼)
    ├─ headRatio低头检测 (<0.38 → 低头)
    └─ turnRatio转头检测 (<0.62 → 东张西望)
    ↓
状态判定 → focused / distracted / away
    ↓
┌───────────────────────────────────────┐
│          同时联动                      │
├────────────────┬──────────────────────┤
│  Web 前端       │  ESP32 硬件          │
│  - 番茄钟倒计时  │  - 像素宠物表情切换   │
│  - 状态指示器    │  - 数字倒计时显示     │
│  - 统计图表      │  - 警告闪烁          │
│  - 今日计划      │                      │
└────────────────┴──────────────────────┘
```

## 五、使用场景

1. **学生自习：** 打开FocusBuddy，点击开始，摄像头开始检测。
   专注时宠物🐱开心；走神时宠物😟担心；离开座位移开视线时宠物😴睡觉。
   番茄钟25分钟完成后，⭐记录+庆祝动画🎉
2. **远程办公：** 用浏览器打开即可工作，页面自动记录专注时长，
   下班后查看今日专注率和走神次数
3. **学习习惯养成：** 7天柱状图展示专注趋势，
   今日计划功能帮助提前规划学习任务
