# FocusBuddy — 学习专注伴侣

## 一句话
摄像头盯着你学习，不好好学习Dream会生气😡

## 痛点
- 走神不自知：学一会儿就刷手机，不知道自己偷懒了多久
- 缺乏动力：番茄钟太枯燥，没人监督容易放弃
- 不了解自己：不知道一天真正专注了多少时间
- 提醒太烦：手机闹钟不是忘了就是嫌烦关掉

## 解决方案
FocusBuddy 用摄像头捕捉面部特征，通过 MediaPipe FaceMesh 进行 468 点面部网格分析，
实时判断专注/走神/离开状态，联动：
- 🍅 番茄钟倒计时（25分钟专注 / 5分钟休息）
- 🐱 ESP32 8×8 LED 像素宠物（4种情绪表情实时变化）
- 📊 专注统计仪表盘（当日数据 + 图表分析）
- 📋 今日计划（输入提示词自动生成待办清单）

## 技术实现
- 面部检测：MediaPipe FaceMesh（Web端），闭眼检测(EAR)、低头检测(headRatio)、转头检测(turnRatio)
- 前端：原生 HTML/CSS/JS + Chart.js
- 硬件：ESP32-S3-Matrix (8×8 NeoPixel)，WiFi AP模式，HTTP API通信
- 存储：localStorage（专注统计、设置、计划）

## 创新点
- 物理反馈（LED宠物）比软件弹窗更温和但有效
- 番茄钟 × 面部检测的闭环联动
- 8×8 矩阵显示数字倒计时（自定义5×3字体）
- 纯浏览器端运行，无需安装

## 使用方式
1. 打开 https://github.com/Sapnap67/FocusBuddy
2. 启动本地 HTTP 服务器 (python -m http.server 8080)
3. 浏览器打开 index_new.html，允许摄像头
4. 点击"开始专注"开始学习
