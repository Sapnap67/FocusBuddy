# FocusBuddy — PPT 大纲（10分钟路演）

> 赛道：原型开发组 | 时长：10分钟 | 讲述人：Ryan + Vickie

---

## 第1页：封面 (15s)
**FocusBuddy — 学习专注伴侣**
- 副标题：摄像头实时检测 + 番茄钟 + ESP32像素宠物
- Dream Team
- Ryan（前端）、Vickie（硬件+视觉）
- HHCC 2026

## 第2页：痛点 (60s)
**自习时，你知道自己走神了多久吗？**
- 场景：学生坐在书桌前，一边写作业一边刷手机
- 数据：研究表明，平均每15分钟走神1次
- 问题：
  - ❌ 走神不自知
  - ❌ 番茄钟只管定时，不管你是否在看屏幕
  - ❌ 没有数据反馈，不知道一天真正专注了多少
- "所以我们需要一个**看得见的专注伴侣**"

## 第3页：解决方案 (60s)
**FocusBuddy 闭环**
- 视觉展示：系统架构图
- 核心流程：
  ```
  摄像头 → FaceMesh检测 → 状态判定 → 番茄钟 + 宠物表情 + 统计数据
  ```
- 三合一：检测 + 计时 + 反馈
- "不是简单的番茄钟，也不是单纯的摄像头——是**两者联动的闭环**"

## 第4页：产品展示 — 界面 (90s)
**Web 仪表盘**
- 🎬 **现场演示 / 录屏播放**
- 摄像头画面区
- 番茄钟大号倒计时
- 状态指示器（🟢专注/🟡走神/🔴警告/⚪未开始）
- 今日统计（专注时长/走神次数/完成番茄数/专注率）
- Chart.js 饼图+柱状图
- 📋 今日计划：输入"写论文2小时"→自动生成待办

## 第5页：产品展示 — 硬件 (60s)
**ESP32 像素宠物**
- 🎬 **现场演示 / 硬件照片**
- 8×8 LED 矩阵
- 4种情绪：😊开心(绿) / 😟担心(黄) / 😡愤怒(红) / 😴睡觉(蓝)
- 倒计时数字显示（5×3自定义字体）
- 离开>10s → 红色警告闪烁
- 番茄完成 → 🎉庆祝动画

## 第6页：技术实现 (60s)
**技术架构**
- 视觉检测：MediaPipe FaceMesh（468点面部网格）
- 检测算法：
  - EAR < 0.22 → 闭眼
  - headRatio < 0.38 → 低头
  - turnRatio < 0.62 → 转头
- 前端：原生 HTML/CSS/JS + Chart.js
- 硬件：ESP32-S3-Matrix，WiFi AP通信
- "三个检测维度覆盖了自习走神的主要场景"

## 第7页：创新点 (60s)
**为什么不一样？**
| 传统番茄钟 | FocusBuddy |
|---|---|
| 只管倒计时 | 检测+计时联动 |
| 手机闹钟提醒 | 物理LED宠物表情 |
| 无数据记录 | 专注率+7天趋势 |
| 单一功能 | 计划+检测+统计+硬件 |

## 第8页：演示视频 (120s)
**完整使用流程**
- 🎬 **播放 2分钟演示视频**
- 用户打开页面 → 允许摄像头 → 开始专注
- 专注时宠物开心，走神时宠物担心
- 离开座位 → 番茄钟暂停 → 红色警告
- 番茄完成 → 庆祝动画 + 数据记录
- 查看当日统计和7天图表
