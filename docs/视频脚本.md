| 素材 | 推荐工具 | 时长 | 说明 |
|------|----------|------|------|
| 录屏演示 | OBS Studio | 2min | 全流程从打开到番茄完成 |
| ESP32 特写 | 手机横屏拍摄 | 30s | 4种表情切换+数字倒计时 |

### 推荐录制流程
1. 架好 OBS Studio（录频软件），选择1080p 30fps
2. 打开 `index_new.html`（本地服务器）
3. 另开手机或相机架三脚架拍ESP32
4. 先录全流程操作（2分钟）
5. 再补拍开头和结尾出镜（30秒）
6. 最后补拍ESP32特写（30秒）
7. 剪辑合成：剪映/CapCut 免费版
